# Confluence REST API — описание методов

## GET `/rest/api/content`

**Get content**

Returns a paginated list of Content.

### Query-параметры

| Параметр | Тип | По умолчанию | Описание |
| --- | --- | --- | --- |
| `type` | string | `page` | the content type to return. Default value: page. Valid values: page, blogpost. |
| `spaceKey` | string | — | the space key to find content under. |
| `title` | string | — | the title of the page to find. Required for page type. |
| `status` | string | — | list of statuses the content to be found is in. Defaults to current is not specified. If set to 'any', content in 'current' and 'trashed' status will be fetched. Does not support 'historical' status for now. |
| `postingDay` | string | — | the posting day of the blog post. Required for blogpost type. Format: yyyy-mm-dd. Example: 2013-02-13 |
| `expand` | string | — | a comma separated list of properties to expand on the content. Default value: history,space,version. |
| `start` | int | — | the start point of the collection to return |
| `limit` | int | `25` | the limit of the number of items to return, this may be restricted by fixed system limits |

## POST `/rest/api/content`

| Параметр | Тип | По умолчанию | Описание |
| --- | --- | --- | --- |
| `status` | string | `current` | — |
| `expand` | string | `body.storage,history,space,container.history,container.version,version,ancestors` | A comma separated list of properties to expand on the content. Default value: history,space,version |

## PUT `/rest/api/content/{contentId}`

**Update**

## DELETE `/rest/api/content/{id}`

**Delete**

Trashes or purges a piece of Content, based on its {@link ContentType} and {@link ContentStatus}. There are three cases: If the content is trashable and its status is {@link ContentStatus#CURRENT}, it will be trashed. If the content is trashable, its status is {@link ContentStatus#TRASHED} and the "status" query parameter in the request is "trashed", the content will be purged from the trash and deleted permanently. If the content is not trashable it will be deleted permanently without being trashed.

### Query-параметры

| Параметр | Тип | По умолчанию | Описание |
| --- | --- | --- | --- |
| `status` | string | — | the status of the content to be deleted |

### Ответы

**200** — `application/json`

Returned if successfully trashed.
**204**

Returned if successfully purged.
**404**

Returned if there is no content with the given id, or if the calling user does not have permission to trash or purge the content.
**409**

Returned if there is a stale data object conflict when trying to delete a draft
